# Contributing

Thanks for your interest in contributing!

## How to contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-topic`.
3. Make your changes with clear commits.
4. Push and open a Pull Request.

## Guidelines

- Keep each topic focused; one concept per folder.
- Use clear, well-commented examples.
- Follow existing naming and formatting.
- Update README/webpage if you add a new topic.

## Code of Conduct

Be respectful and constructive in all interactions.
